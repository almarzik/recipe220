# Станция рецептов · SS220

Статический сайт: рецепты, медицина, ботаника, наука, инженерия, СБ и сборки игроков.

## Структура

```text
index.html                  Разметка страницы и порядок подключения модулей
src/
  app.js                    Каталог рецептов и рабочее поле
  components/               Общие компоненты интерфейса
    navigation.js           Переключение разделов и видимость рабочего поля
    medicine-card.js        Отрисовка карточки лекарства
  features/
    recipes/                Химические расчёты и меню повара
    medical/                Подбор лекарств и стили медицины
    botany/                 Ботаника
    scientist/              Артефакты и аномалии
    engineering/            Атмос, экономика и суперматерия
    security/               Космический закон и расчёт срока
    players/                Сборки игроков
  styles/                   Общие стили и адаптивная вёрстка
data/                       Готовые данные для браузера
assets/                     Миниатюры и сведения об источниках изображений
player-guides/              Оригиналы методичек игроков
sources/                    Исходные документы для сборщиков
scripts/
  build/                    Генераторы данных и изображений
  project-paths.cjs         Корень сайта и путь к исходникам SS14
tests/                      Проверки интерфейса и расчётов
server.cjs                  Локальный статический сервер
```

## Запуск

Node.js: `npm start` → http://127.0.0.1:4173. Готовому сайту не нужна сборка и установка зависимостей. Для GitHub Pages загрузите содержимое проекта с сохранением папок, включая `src`, `data` и `assets`; корневой документ — `index.html`. Работает и открытие index.html с диска: скрипты обычные, без ES modules и запросов за данными.

## Данные и тесты

`npm ci` устанавливает зависимости сборщиков и тестов. `npm test` запускает тесты из tests. `npm run build` обновляет рецепты, науку и инженерию; отдельные команды перечислены в package.json. Медицина содержит вручную сверенную подборку в data/medical-data.js и не перезаписывается этими генераторами.

Путь к игре задан в scripts/project-paths.cjs. На другом компьютере укажите `SS14_ROOT`, например в PowerShell:

```powershell
$env:SS14_ROOT = 'C:\Users\almar\Desktop\ss14llocal\space-station-14'
npm run build
npm test
```

Тесты сверки прототипов требуют локальный билд. build:security читает сохранённый sources/security-source.html, build:players — player-guides/chemistry-original.txt. Импорт не меняет файлы игры.

## Как вносить изменения

Разметка и логика раздела — в его папке features, данные — в data. Общий компонент — в components. Зависимости подключаются в index.html перед потребителем, с defer; их порядок важен. При добавлении раздела обновите кнопки и секции index.html, реестр pages в components/navigation.js. Модули расчётов сохраняют CommonJS-экспорт для тестов. Состояние рабочего поля и заметок по-прежнему хранится в браузере под прежними ключами.
